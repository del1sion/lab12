Основні команди Git

Створення репозиторію

Створити локальний репозиторій:

git init [project_name]

Клонувати репозиторій:

git clone my_url

Перегляд репозиторію

Статус файлів:

git status

Зміни в робочій папці:

git diff

Зміни підготовлених файлів:

git diff --cached

Усі зміни від останнього коміту:

git diff HEAD

Різниця між двома комітами:

git diff commit1 commit2

Історія змін файлу:

git blame [file]

Зміни певного коміту:

git show [commit]:[file]

Повна історія комітів:

git log

Історія конкретного файлу:

git log -p [file/directory]

Робота з гілками

Локальні гілки:

git branch

Усі гілки:

git branch -av

Перехід на гілку:

git checkout my_branch

Створення гілки:

git branch new_branch

Видалення гілки:

git branch -d my_branch

Злиття гілок:

git checkout branch_b
git merge branch_a

Створення тегу:

git tag my_tag

Внесення змін

Підготувати файл:

git add [file]

Підготувати всі зміни:

git add .

Створити коміт:

git commit -m "commit message"

Коміт змінених відстежуваних файлів:

git commit -am "commit message"

Прибрати файл з індексу:

git reset [file]

Скинути зміни до останнього коміту (обережно):

git reset --hard

Синхронізація

Отримати зміни:

git fetch

Отримати та об'єднати зміни:

git pull

Отримати зміни з перебазуванням:

git pull --rebase

Відправити зміни:

git push

Допомога

Довідка Git:

git command --help
