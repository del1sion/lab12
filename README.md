# Лабораторна робота 1.12. Git і GitHub

Сайт за прикладами зі слайдів: форма реєстрації та сторінка з командами Git.

## Склад файлів

- `index.html` — головна сторінка з посиланнями.
- `register.html` — форма реєстрації.
- `register.js` — перевірка збігу паролів (демо, без сервера).
- `git_commands.html` — довідник команд Git.
- `style.css` — оформлення всіх сторінок.

Відкрийте `index.html` у браузері. За потреби замініть назву групи у `register.html` і текст у шапці та підвалі на власні дані.

## Гілки і коміти

За методичкою початковою основою має бути **попередня лабораторна 1.10**. У її репозиторії зробіть коміт `Version 1.0.0` у `master`, потім створіть `develop`. Далі форму потрібно створити в `task_1.12`, а довідник Git — у `git_commands`. Після завершення кожну гілку слід злити в `develop`, але самі гілки не видаляти.

**Важливо:** просте завантаження ZIP або всіх HTML-файлів на GitHub не створює історію гілок. Коміти за кожним полем форми потрібно робити під час покрокового створення полів; уже готові файли автоматично не створять таку історію. Приклад команд дивіться в окремому файлі `GIT_STEPS.md`.

## Публікація

Статичні сторінки можна розмістити на Netlify, завантаживши папку з `index.html`. Форма працює як демонстрація і не зберігає акаунти.
